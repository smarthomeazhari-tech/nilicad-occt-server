# نصب موتور STEP دقیق NiliCAD روی Render

1. فایل‌های `server.py`، `requirements.txt`، `Dockerfile`، `.dockerignore` و `render.yaml` را در ریشه یک مخزن GitHub جدید (مثلاً `nilicad-occt-server`) قرار دهید. فایل `index.html` برای خود وب‌سایت است و لازم نیست روی سرور Docker قرار گیرد.
2. به https://dashboard.render.com بروید، **New → Web Service** را انتخاب کنید، GitHub را وصل و مخزن جدید را انتخاب کنید.
3. **Language/Runtime = Docker**، **Dockerfile Path = ./Dockerfile**، نام `nilicad-occt` و پلن مناسب را انتخاب کنید؛ سپس **Deploy Web Service** را بزنید.
4. بعد از نمایش وضعیت **Live**، آدرس اختصاصی `https://<نام-واقعی-سرویس>.onrender.com/health` را باز کنید. پاسخ باید شامل `"ok":true` باشد.
5. در NiliCAD، **انتخاب موتور CAD → سرور اینترنتی** را بزنید، آدرس HTTPS واقعی را بدون `/health` وارد کنید، **آزمایش اتصال** و سپس **STEP دقیق** را بزنید.

## توجه
- این بسته آماده انتشار است ولی خودِ سرویس Render در حساب شما ایجاد نشده و آزمایش واقعی STEP هنوز انجام نشده است.
- نسخه آزمایشی API به‌طور پیش‌فرض عمومی و بدون احراز هویت است؛ برای استفاده شخصی یا تولیدی حتماً احراز هویت، محدودیت اندازه ورودی و کنترل منابع اضافه کنید.
- سرویس رایگان Render ممکن است پس از بیکاری به خواب برود و اولین درخواست دیرتر پاسخ دهد.
- بعضی تاریخچه‌های Mesh قدیمی در موتور B-Rep بازسازی‌پذیر نیستند. ابتدا با یک مکعب یا استوانه جدید آزمایش کنید.
